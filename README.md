# Caesar Cipher Using Python

## Project Description

This project is a simple command-line Python program for encrypting and decrypting messages using the Caesar Cipher technique.

## Features

- Encrypt a message
- Decrypt a message
- Choose a shift value
- Works directly in the terminal

## Requirements

- Python 3.x

## How to Run

1. Install Python 3.x.
2. Download or clone this repository.
3. Open the project folder in the terminal.
4. Run the program using:

python main.py

## How It Works

The program takes a message and a shift value from the user. It shifts alphabetic characters according to the selected shift value. For decryption, the reverse shift is applied.
